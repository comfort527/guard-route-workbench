# 警衛路線工作台

這個 repo 只放**加密過**的工作台。`index.html` 打開後要先輸入密碼，沒有密碼的人只看得到一串亂碼，裡面的地圖金鑰、常用地點、寫法記憶與歷史路線都看不到。

## 更新網站的方法

1. 用瀏覽器打開工作台（本機檔案，或這個網站登入後都可以）。
2. 按右下「設定」→「部署到網站（加密）」，輸入開啟密碼兩次，按「產生加密的 index.html」。
3. 把下載的 `index.html` 上傳到這個 repo，取代舊檔（GitHub 網頁：Add file → Upload files）。
4. 大約一分鐘後，網站就會換成新版本。

## 注意

- **不要把未加密的工作台 HTML 放進這個 repo。** git 會永久保留每一版的紀錄，就算之後刪掉也找得回來。
- 密碼不會存在任何地方，忘了只能用新密碼重新產生。
- 地圖金鑰仍然要在 Google Cloud Console 設定網站限制（只允許這個網站的網址）、API 限制與每日配額上限。加密只能防止金鑰被掃描收集；知道密碼、打開網頁的人，還是能從瀏覽器的開發者工具看到金鑰。
